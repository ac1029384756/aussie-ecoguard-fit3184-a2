## 本次代码改动

- API 返回非 JSON 的 401 时也触发会话失效，防止网关 HTML 错误绕过前端退出逻辑。
- 失效时清理 Amplify 会话后再显示登录界面，避免旧 SDK 登录态妨碍重新登录。
- 通过会话版本拒绝迟到的身份读取结果，防止过期或退出后恢复旧用户。
- 注册/登录请求进行中禁用流程切换、姓名和验证码输入；临时密码和 OTP 挑战锁定
  账号邮箱；注册拒绝全空白姓名。
- 密码输入有独立可访问名称，密码规则作为说明关联，便于辅助技术和稳定交互。
- 新增注册、邮箱确认/重发、错误验证码、登录、临时密码、重置密码、忙碌状态、
  过期提示、非 JSON 401 与身份读取竞态测试。

未更改后端业务实现、基础设施、模型、依赖清单或云端暂停配置。
